## First playable decision and cost

Take Medical Herb (ID 0) from the selected private pack, derive its normal/selected pair **locally**, and review it beside the originals before promoting either frame. The lantern never substitutes for the herb. Use one existing field inventory with a second uncovered identity and its existing public text case. At production size on light and dark surroundings, ask a player to identify the herb and distinguish selection without a label cue. Inspect holes, palette, outer rim and alignment against both original frames. Reject any broken transparent hole, lost selection cue, altered anchor or unexplained expansion beyond one display pixel. An overlap percentage alone cannot accept the art.

Toggle Original → HD → Original in one session, then reopen the same inventory, cancel a draft, relaunch and load the same slot. Observe unchanged item/slot, dimensions, input target and session state across Apply, actual texture selection and fallback for the uncovered item, override/write-failure behavior, persisted mode, and absence of adapter errors. Use existing running-instance state/input observations plus human viewing. The field-pair pilot ended here. The player subsequently requested the [whole Map3 comparison](asset-inventory.md). If recognition or registration fails, retain Original and return the pair for revision.

**Planning estimate:** assuming the existing world publisher and field UI owner suffice, allow ½ day for pair preparation/review and 1–2 developer days for admission, host wiring and observation. Two 64×96 RGBA frames occupy 48 KiB decoded per pair (vs. 3 KiB at 16×24); allow two copies briefly at swap plus decoder/driver overhead. Offline filtering and decoding are linear in the pixels processed. A field-only variant in one world adds about 64 KiB base64 before metadata if raw RGBA is embedded; avoid republishing seven battle copies. In the proxy trial the cloud master was 1,828,322 bytes, the delivered C was 8,511 bytes, B was 742 bytes, and the single edit returned in about 23 seconds. Per-call billing, GPU residency and live switch latency were not measured. First slice budgets zero cloud edits of private art. Allow at most one half-day art revision before reviewing scope; stop if a fresh asset platform or whole-scene reload would be needed.
