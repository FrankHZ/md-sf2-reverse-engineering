# Named ROM split families

Use the [ROM ledger lookup](rom-block-ledger.md#look-up-a-split-file) with a ROM file offset or an exact split path. Use `--family ID` to list that row's members with their physical ranges. The rules below apply to the case-sensitive path after `data/` in the pinned split inventory. A wildcard can span directory separators. Every active name must match exactly one row.

**Confirmed** physical bounds come from the split directive. The depth column describes what the cited material establishes for that member. **Corpus** identifies a documented data format or whole-resource inventory. **Use** identifies a specific consumer or an interpreted subset. **Location** identifies a source placement with **Unknown** internal semantics. Counts of bytes in files at each depth measure stored extents. Decoded byte counts and runtime observations use their owners' denominators.

## Checking a leaf

For an unfamiliar member, use its exact path from the lookup in the pinned source search below. Follow the matching incbin and symbol into the section layout and its references. The debug-script entry leads to `disasm/data/scripting/map/debugscripts.asm` at `DebuggingScript`. The source comments on a parsing mistake and leaves 120 bytes unformatted. Individual commands and execution remain **Unknown**. Two title layout splits are binary mirrors of assembled source. The four source-only icon names repeat ranges assembled under other names. Both cases can produce a split match without an incbin for that exact path.

```powershell
$source = (Get-Content -Raw manifests/toolchain.json | ConvertFrom-Json).sf2disasm
$pin = $source.commit
$upstream = $source.localPath
$member = 'data/scripting/map/debuggingscript.bin'
git -C $upstream grep -n -F $member $pin -- disasm
```

The battle palette has a source-level copy into `PALETTE_3_BASE`. The Sega logo uses the color table through an indexed load and the palette through a separate pointer. The members-list and spell-level callers load the text-highlight tile symbol. The **Use** rows identify these seams without assigning meaning to every word.
