# L2 · 北方旅行至首次 Pacalon 章节总览

- **章节范围（仅覆盖北方路线前半段至首次旱灾状态 Pacalon）：** 承接矮人矿洞取得 **Cannon**（[南方旅行、车队与 Creed 章节总览](../southern-travel-creed/chapter-overview.md)），覆盖重返**新格兰希尔**（**阿斯特拉尔**、发明家 **Dynamite** 与 **Janet**）、**北 Parmecia 道路**（`Battle24`）、炮轰 **North Cliff** 并正式招募**罗德（Rohde）**、穿越 **North Cave**（`Battle25`）、探访 **Ketto**（商人搬迁与教堂）、**Geshp** 伏击战（`Battle26`）营救 **Higins**，以及**旱灾状态 Pacalon 城镇与城堡**（含常驻 **Frayja**），止于离开 Pacalon 南出至旱灾大地图（`Battle27` 之前）。
- **本章目标与世界变化**：向新格兰希尔国王汇报 Elis 尚在人世，**阿斯特拉尔**转为常驻军师随行，镇上发明家为 **Cannon** 配发 **Dynamite**，南门外招募 **Janet** → 扫清北路（`Battle24`）并炮轰 **North Cliff** 消耗两件爆破道具、正式招募**罗德**并打通 **North Cave**（`Battle25`） → 抵达 **Ketto** 促成商铺开张并可选更新北方返回点 → 击退 **Geshp** 伏击（`Battle26`）救出 **Higins**，步入**旱灾状态 Pacalon 城镇与城堡**，为北上 Tristan 与 Mitula 做好准备。
- **超出本 B3 总览的后续内容（不在此展开）：** **`Battle27`**、**Pangoat Valley Bridge**（`Battle28`）、**Tristan**、**Mitula 神殿**（`Battle29`–`Battle30`）、**恢复降雨**（以及雨后 Pacalon）、**`Battle31`** 与**后期 Frayja 随行/入队**均**不在本 B3 总览范围内**（且重制版目前**尚未可玩**至 `Battle27` 及之后）。请参阅[剧情推进 · 北方旅行、Pacalon、Tristan 与 Mitula](../../themes/story-progression.md#北方旅行pacalontristan-与-mitula)以及文末链接的 3 篇 `Battle27` 延伸段级页。

## 按实际依赖组织的事件与分支总表（玩家视角）

*本章有三条容易误解的核心规则：*
- **新格兰希尔三件事条件彼此独立：** 城堡觐见与**阿斯特拉尔**随行**不检查**是否持有 Cannon；找发明家领 **Dynamite** 需要先完成觐见且军团背包实际携带 Cannon；**Janet** 入队只看是否完成觐见（不要求 Dynamite、埃尔里克在场或出战空位）。
- **军团携带背包 ≠ 车队仓库（Depot）：** 发明家与 North Cliff 都只扫描**已入队成员的携带背包**（含后备与倒下成员），**不会**检索车队仓库里的物品。
- **没有固定强制撤退点：** `Battle24`、`Battle25` 与 `Battle26` 的败北或撤离（`EGRESS`）全部回到你**当前已保存的教堂返回城镇**（例如未在 Ketto 或 Pacalon 存档前仍是 Hassan）——这三场战斗都不会写死退回 North Cliff 或 Pacalon。

## 本章关键道具与 Cannon / Dynamite 链路

*详细持有、掉落与装备规则见[物品索引（英文源）](../../../../../../remake/docs/content/campaign-items.md)。*

### 本章核心道具链（各环节持有范围不同）

1. **Cannon（承接 B2 → `N2` → `N5`）：** B2 矮人矿洞中严格发给鲍伊本人的 4 格背包；到了新格兰希尔发明家（`N2`）与 North Cliff（`N5`），改为检查**所有已入队成员的携带背包**（含后备与倒下成员），但**车队仓库（Depot）里的存货不算**。发明家不消耗 Cannon，North Cliff 爆破才会将其与 Dynamite 一同消耗。
2. **Dynamite（`N2` → `N5`）：** 完成城堡觐见（`N1`）且军团背包带着 Cannon 时由新格兰希尔发明家发放，进入**第一个有空位的已入队成员背包**（全军团满包则礼貌拒绝、清位后可重试），随后在 North Cliff（`N5`）与 Cannon 一同消耗。
3. **North Cliff 缺物拒绝与重试陷阱（`N5`）：** 缺少 **Cannon 或 Dynamite 任一件**时，拒绝台词都会说成缺少 **Dynamite**、不消耗道具，并立下**当次访问锁**。由于仅做大地图跨屏滚动不会解除此锁，从车队仓库取出 Cannon 后，必须**实际进一次城镇（如新格兰希尔）再走出**，North Cliff 才会重新检验背包。

## 证据与边界说明

- **原版边界**：本总览覆盖的北方旅行至首次 Pacalon 段落（`N1`–`N9`）在锁定源码（`SF2DISASM` `c834c652b6862bc5679fd7f69a38a7093206efc6`）与美版 ROM 中为**已确认静态**（[Cannon 与 North Cliff 覆盖（英文源）](../../../../../research/story-content-coverage.md#returning-for-the-cannon-and-opening-north-cliff)、[Ketto、Higins 与旱灾 Pacalon 覆盖（英文源）](../../../../../research/story-content-coverage.md#ketto-higins-and-drought-state-pacalon)）。原版运行时观察止于前期 `Map3`–`Battle01`；本章自然连续步行、硬件时序、呈现表现与原版断电存档持久性仍为**未知**。
- **重制边界**：重制版已有双语普通连贯游玩与冷启动存读档覆盖新格兰希尔返回（阿斯特拉尔、Dynamite、Janet）、`Battle24`、North Cliff 爆破与罗德（含仓库遭拒与进城重试）、`Battle25` 与 North Cave（`Fairy Tear` 场地拾取）、Ketto（商人搬迁、教堂存/取消、商店与拾取）、`Battle26` 与 Higins，以及旱灾状态 Pacalon 城镇与城堡（半人马/楼梯、常驻 Frayja、镇城独立教堂、拾取、转职与受控 `Map71` 离开）（[重制能力状态（英文源）](../../../../../../remake/docs/capability-status.md#campaign-feature-trace)）。**`Battle27`、Tristan、Mitula、雨后 Pacalon（`F530`）、`Battle31` 与后期 Frayja 招募在重制版中均尚未可玩**（见[剩余战役基线（英文源）](../../../../../../remake/docs/application/remaining-campaign-risk-baseline.md)）。
- **原版未知 ≠ 重制未实装**：旧段级页中的原版**未知**只界定原版运行证据边界，不代表重制版未实现；重制版通过也不反证原版自然时序。
