# Battle26 返回至有条件 Pacalon 入口

## 从返回地点到城门

**已确认：**胜利使用营救前准备的战斗回点；败北和合法撤退走存档点，分别承担不同代价。返回后的新探索重建当前人物。Higins 已加入的身份保留，演出请求的跟随不是后续固定随从。向东滚动保持当前探索人员，并不直接启动另一遭遇；已取得木筏是否出现，还须其当前泊位与新地图一致。

到 Pacalon 的普通传送让战斗选择先于居民入场：已解锁的 Battle31 可被优先选中，未准入则按 Pacalon 的剧情状态选择尚在城内的人群。仅在待处理事件清空之后才可安装与当前模式对应的步行或载具控制。自然走到城门和持续保存为**未知**。
