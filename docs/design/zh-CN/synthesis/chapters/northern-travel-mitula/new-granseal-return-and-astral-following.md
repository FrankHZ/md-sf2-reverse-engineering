# 返回 New Granseal 与 Astral 跟随

## 再访与顾问的决定

**已确认：**从矿洞返回以及进入城堡各为独立请求。旧 Peter 觐见、更晚的返回状态与在场者不是同一条件；城堡中返回觐见有自己的资格和完成记录。未完成才触发王室听闻 Elis 仍在世、委托救援、批准 Astral 同行。Astral 的提议是演出，没有玩家拒绝。取得炮和炸药、开洞、再招募各由后续选择和服务处理。

宣布后请求 Peter 跟随，并把 Astral 加入当前跟随队列。Astral 是顾问，加入当前场地队列不授予出战资格。之后记录城堡和随从所需状态，重新进入才按它们重建；若只有其中一个状态，不会把整场内容当作已可靠完成或自动修复。普通走出城堡以及从文本回到响应输入仍为**未知**。
