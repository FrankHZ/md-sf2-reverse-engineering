# Fairy Cave 探索与 Devil's Tail 返回

## 四只宝箱与重复搜索

**已确认：**Angel Wing、Brave Apple、Medical Herb 和 Mithril 各有独立宝箱。在实际搜索对应格时，先尝试让 Bowie 接收，再按军团顺序找另一有空位的已加入者（包括后备或倒下者）。全员满时关闭宝箱并恢复可领取状态，腾空后重试；领取后再开只给空宝箱。当前普通交互与主动 Search 的入口不完全相同，先选中的实体交互会吃掉本次普通按键。

## 两个出口和洞外的岩石

两个出口都回 Devil's Tail，其去处与步行之后是否发生 Battle21 分开。若进入过程已选中符合解锁的遭遇，可在重建探索之前交战；否则还可能在之后的步行事件申请。战斗完成后的随机再遇须冷却归零且 0–7 抽出 0，未中重设 2–5 冷却。出洞不清除木筏信息或自动退到步行。

岩石的调查也有条件：未开通，且 Elric 未加入或已倒下时可听到指向帮助的 Peter 答复；Elric 已加入且存活时，该条件下无这段提示。真正开通要走 Elric 的另一项区域请求。因此听提示、搜索奖励、开路和遭遇不是一条必须全做的路线。自然通行仍为**未知**。
