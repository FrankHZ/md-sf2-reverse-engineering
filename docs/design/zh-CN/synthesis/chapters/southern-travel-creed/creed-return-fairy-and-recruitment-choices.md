# Creed 返回、Fairy 跟随与招募选择

## 回到宅邸与 Fairy 的决定

**已确认：**咨询后的居民状态会把可招募人物放到房间内，通常只布置未加入的同伴。更晚的 Oddler 阶段换人口；释放同伴后的访问又覆盖它。Goliath 在通常咨询后鼓励选一人，Creed 给 Tristan 的建议。Fairy 若已听到患病矮人的消息就提议去帮他，否则提出向东同行；两种都接到当前跟随，没有 Yes/No 或正式加入。Bowie 倒下可跳过跟随请求而仍留下交谈完成。临时跟随可能改变下一次招募时的跟随目标。

## 选择一名同伴，再访时的选择

| 条件 | Yes | No 或 B |
| --- | --- | --- |
| 初期，还没有接受同伴 | 正式加入所选的 Eric、Randolf、Tyrin 或 Karna。安排所选者跟随，并记录已经选过；以后再找其他人，只听到他们各自的拒绝答复，不再给提示。 | 各自回应后结束；仍可再次问，亦可改找他人。 |
| 后来释放同伴的状态 | 可分别接受仍能接触的同伴。每次加入记录选择并尝试跟随，这个较晚条件优先于旧的只选一人的限制。 | 只听对应的较晚分支回应，保留重试和另选。 |

初期拒绝时，Eric 祝军团顺利，Randolf 愿留下、Tyrin 惋惜不能用魔法帮忙，Karna 不满。较晚拒绝时，Eric 提议自己寻剑、Randolf 决定留下、Tyrin 警告会后悔，Karna 认为无礼。没有先选一人的完成记录并不保证该人物现在能见到；普通交互仍看重建与在场状态。

已加入者能否立即出战还取决于十二人容量，满队不逐出原有成员。跟随新增人物选当前跟随序列末尾（空时跟随领队），不是指定 Fairy 或 Peter。接下来 [Oddler 告别](oddler-stays-and-fairy-handoff.md)有独立区域条件，不要求先招募任一人。自然顺序、控制和持久性为**未知**。
