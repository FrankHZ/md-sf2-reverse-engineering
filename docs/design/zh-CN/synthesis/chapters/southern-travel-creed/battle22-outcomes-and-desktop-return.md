# 棋盘结果与返回 Desktop Kingdom

## 胜败结算

**已确认：**King 倒下、Bowie 存活时可经首领清理让剩余棋子退出计数；Bowie 同死仍先败北。胜利恢复符合条件的伙伴，并按首名出战者最终位置和朝向回 Desktop；首次和重复都不因空战后段而跳过正式完成处理。败北恢复 Bowie、金币减半；合法 EGRESS／Angel Wing 使用资源但保留金币。两者用保存的撤退地点，不设胜利完成。直接返回不重新扫描遭遇。

Desktop 重新按当前状态建人群、门和宝箱。当地尚未记录抵达时先呈现抵达，之后才检查另一公告：必须 Battle22 已胜利且尚未宣布奖励。公告当场描述 Cotton Balloon；没有把物品加入军团。完成公告后再次回来不会播同一句；宝箱能否打开以及真正领到气球另行检查。可以再与 Ponpei、Maid 交谈，Maid 在同次入场的后续交谈会给另一回应。后续使用和离开看[气球与 Floor World](cotton-balloon-through-floor-world-entry.md)。自然控制与保存为**未知**。
