# L2 · 南方旅行、车队（Caravan）与 Creed 章节总览

- **章节范围**：承接 Polca 登乘木筏并迈出水上第一步（[新格兰希尔与东部 Parmecia 章节总览](../eastern-parmecia/chapter-overview.md)），覆盖南下水路与 **Kraken**（`Battle16`）、**Hassan**、东南沙漠（`Battle14`）与 **East Shrine / Ancient Hall**（`Battle15`）取得 **Wooden Panel**、**Ribble** 树洞取得**阿喀琉斯之剑（Achilles Sword）**、**Rohde** 与**塔罗斯（Taros）**神殿（`Battle18`）、取得并驾驶**车队（Caravan）**、**Elven Village**（`Battle19`）、**Harpy Pond** 营救**埃尔里克（Elric）**（`Battle20`）、**Fairy Cave** 与 **Devil's Tail**（`Battle21`）、**Creed 宅邸**、**Desktop Kingdom / 棋盘**（`Battle22`）、**Floor World / Willard Burrow**（`Battle23`）、恢复体型、**Evil Spirit Shrine** 咨询、Creed 四选一招募与 **Oddler / Fairy** 交接，最终止于 **Dwarven Mine** 妖精治愈矮人并领取（或满包延后领取）**Cannon**。
- **本章目标与世界变化**：乘木筏南下击退 Kraken 抵达 Hassan → 寻获 Wooden Panel 与阿喀琉斯之剑，说服 Rohde 引路击败塔罗斯并赢得车队 → 驾驶车队跨过干涸河床进入西南 Parmecia，救出埃尔里克打开 Fairy Cave 抵达 Creed 宅邸 → 误入魔法门缩小后历经桌面棋盘与地板世界、恢复原状并得知**泽翁（Zeon）**的索求，随后在四名同伴中招募一人、留下 Oddler 并由妖精带路前往矮人矿洞取得 Cannon。
- **后续内容（不在本 B2 展开）**：北返新格兰希尔找阿斯特拉尔（Astral）、向发明家取 **Dynamite**、招募 Janet、炮轰 North Cliff（届时 Rohde 才正式入队）及北方路线（`Battle24`–`26`+）归 `#2366` B3 片（见[剧情推进 · 北方旅行、Pacalon、Tristan 与 Mitula](../../themes/story-progression.md#北方旅行pacalontristan-与-mitula)）。

## 按实际依赖组织的事件与分支总表（玩家视角）

*战斗编号（`Battle14`–`Battle23`）**不是**固定不变的必经顺序：*
- 正常乘筏南下时，河道 **Kraken（`Battle16`）** 发生在东南沙漠（`Battle14`）与 East Shrine 神殿（`Battle15`）**之前**。
- 取得车队渡过河床后，进入 **Elven Village** **不要求**先打赢 `Battle19`。
- 各可选内容（**Rick**、**Elven Village** 二访、**Fairy Cave** 宝箱、后期 **Frayja** 入队后的 Creed 补招）均受各自地图与剧情条件约束，而非统一截止窗口。

- **原版边界**：本章全部段落（`S1`–`S16`）在锁定源码（`SF2DISASM` `c834c652b6862bc5679fd7f69a38a7093206efc6`）与美版 ROM 中为**已确认静态**（[南部覆盖（英文源）](../../../../../research/story-content-coverage.md#southern-parmecia-transport-the-sword-and-taros)、[Creed 覆盖（英文源）](../../../../../research/story-content-coverage.md#creeds-small-worlds-and-the-consultation)）。原版运行时观察止于前期 `Map3`–`Battle01`；本章自然连续步行、硬件时序、呈现表现与原版断电存档持久性仍为**未知**。
