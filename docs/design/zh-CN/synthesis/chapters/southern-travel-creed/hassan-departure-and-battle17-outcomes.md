# Hassan 出发、Battle17 进入与条件返回

## 离开城镇与随机重遇

**已确认的旧审阅范围：**实际从城镇出口请求大地图后，地图的有序准入可能先选已解锁的 Battle09 或 Battle17；没有匹配才回探索。选定步行区域可请求 Battle17；未完成时直接请求，完成后冷却非零就不掷。归零时，0–7 得 0 才请求，否则改设 2–5 的冷却。木筏不通过同一个步行区域回调提出遭遇。

## 结果、重试与已保存的筏

Bowie 倒下先判败北。取胜恢复符合条件队员，按出战首位战斗结束的位置、方向回大地图；完成并清除本战解锁，不因空场景省略结算。再次获胜同样用当前回点，不另给固定剧情或物品。败北恢复 Bowie、扣半金币并回本战的 Hassan 存档点；合法 EGRESS／Angel Wing 消耗资源后同点返退，保留金币。未完成时仍可再试，退败不标记胜利。若此前已取得木筏，失败或逃离重置地图外的泊位；回到城里并不自动登筏。自然具体状态仍为**未知**；本节继续以原译文的英文审阅锚为准。
