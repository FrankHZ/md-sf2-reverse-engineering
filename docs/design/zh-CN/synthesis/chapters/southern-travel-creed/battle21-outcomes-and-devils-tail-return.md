# Battle21 结果与 Devil's Tail 返回

## 两种胜利与两种返退

**已确认：**Bowie 存活且首领死亡时，可将其他敌人移出计数。Bowie 倒下优先败北，即使最后一敌也退出。首次符合条件的胜利先恢复合格队员并准备普通回点，再演出 Peter 讨论要见 Creed；表演结束的固定传送覆盖普通回点。重复获胜时完全跳过场景、临时跟随与传送写入，依当前出战名册首位的结束位置和朝向返回。

败北恢复 Bowie、向下减半金币并回存档点；合法 EGRESS／Angel Wing 支付本次资源后按存档点撤退，无败北半金。均不运行胜利后续。回 Devil's Tail 时重建随从和普通人物，场景中的临时关系不自动保留。战后直接返回不马上检查下一场遭遇，需另行走到宅邸入口。可响应输入和自然重访仍为**未知**。
