# Desktop Kingdom：首次抵达与条件控制

## 只在首次运行的抵达

**已确认：**新抵达 Desktop 替换宅邸人物，当前合格随从分别保留自己的存在条件。抵达演出在尚未处理时才安排队伍落下、Peter 提议查看和新的局部跟随，正常返回后才记录。再访不会重新执行落地；棋盘已经完成时根据另一条件可播放奖励公告，完整的首次抵达仍先于公告。

**推断：**缩小与降落把队伍送到 Goliath 的桌面。安排的尺寸、跟随和在场者是本次场景状态，不改变正式军团、属性、物品或载具保存。别的待处理事件先执行，没有时才交回当前模式。实际落点、表现和自然输入仍为**未知**。
