# Hassan Rick 招募与跟随

## Rick 在场和触发不是同一条件

**已确认：**Taros 完成后的 Hassan 人群才提供 Rick 的固定地点；实际候选还要普通相邻交谈，且同次入场尚未完成 Rick 的请求。Caravan 是否实际取得、登乘或使用并不是另外的准入条件。Rick 表示希望同行，没有 Yes/No 提示。先正式加入、按至多十二人的容量决定出战，再尝试局部跟随；不治疗、不装备或改变 AI。

会面结束后抑制同次重复；在当前跟随列表里的 Rick 也不作为普通交谈候选。全新回 Hassan 时，已经加入会让固定放置的 Rick 隐去；临时记录的重置不会重建早前跟随。异常已有成员状态若仍能触发、且本次交流未记录，可重复场景，不创建第二名队员。自然访问和跟随完成是**未知**。
