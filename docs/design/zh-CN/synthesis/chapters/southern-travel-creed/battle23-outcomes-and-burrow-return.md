# Battle23 结果与返回 Willard Burrow

以下为原版已接受的条件与分支。静态规则的实际自然触发以所引证据为限。

击败首领或没有继续计数的敌人可获胜。胜利治疗合格成员，回到由军团状态派生的位置并重建无居民的洞穴。败北及合法 EGRESS 或 Angel Wing 使用适当的存档点，费用与恢复效果不同。
