# 塔后返回至地震城镇入场

## 从塔到城的各次请求

**已确认：**打完 Battle07 后要通过塔楼出口、城堡连接和城堡南出口分别离开。完成后的塔和城堡省略老一段演出，并可在不同地点遇到 Astral 的两次提示，各自在完整结束后抑制重复。两次提示互不作为准入前提。城堡南出口原请求 Granseal；持有地震条件时目标变为受震版本，保留请求的抵达位置和朝向。

## 首访、重访与控制

第一次进入受震城镇先布置守卫与裂缝的演出，再记下已处理状态。再次到达时直接建立改变后的路面，把前次守卫移开而跳过演出。首次动画请求不构成战斗中的伤亡判断；当前图块变化与再加载后依据状态重建也有不同生命周期。只在没有下一项事件待处理时才重新交给普通输入。原版自然贯穿路线仍为**未知**。
