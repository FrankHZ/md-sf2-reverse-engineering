# L2 · Grans 开篇与离岛章节总览

- **章节范围**：普通 New Game 玩家开局（鲍伊在格兰希尔家中醒来）至格兰希尔码头向船长确认登船、起航前往 Parmecia。片头风暴与神庙序幕仅作背景；海上航行、登陆与 `Battle08` 见后续阅读[航行登陆至损坏船只控制](voyage-through-damaged-ship-control.md)与[损坏船只木板选择至 Battle08](../eastern-parmecia/damaged-ship-plank-through-battle08.md)。
- **本章目标与世界变化**：从格兰希尔的平静早晨与首次古代之塔战斗（`Battle01`）→ 国王委任与西进调查耶尔、哈维尔小屋（`Battle02`–`03`）→ 加拉姆伏击、入狱、越狱并夺回**光明宝石**（`Battle04`–`06`）→ 重返遭袭的格兰希尔、深入古代之塔夺得**邪恶宝石**（`Battle07`）、逃离地震毁城并护送王室登船撤离。

## 按剧情时序排列的事件总表（玩家视角）

*可选地点与拾取只要所在城镇或大地图状态仍可进入，就都可折返重访。本章有两个关键的关门节点：**赢得 `Battle07`** 会引发大地震，使震毁的格兰希尔取代遭袭城镇（随之关闭遭袭城镇的居民与 Kiwi 招募，也无法再从震毁城镇西出折返耶尔、哈维尔、加拉姆或南侧神殿）；而在码头**向船长确认出航（`G20`）**则结束整个前期 Grans 探索，直到战役后期才再归来。*

## 证据与边界说明

- **原版边界**：仅 `Map3` 至 `Battle01` 具有受限原版运行实测（[原版观察前沿（英文源）](../../../../synthesis/milestones/map3-battle01-readiness.md#accepted-original-frontier)）；`Battle02`–`07`、地震与出航在锁定源码（`SF2DISASM` `c834c652b6862bc5679fd7f69a38a7093206efc6`）与美版 ROM 中为**已确认静态**，原版自然完整步行、硬件时序与断电存档持久性仍为**未知**。
- **重制边界**：重制版已有从 New Game 到损坏船只 `Map14` 首次控制的普通游玩与 v6 稳定存档观察（[渡海前战役（英文源）](../../../../../../remake/docs/application/pre-voyage-campaign.md)）。片头风暴/神庙演出（`--opening-act 1–4`）属于 `G1`–`G20` 之外的背景段落。命名受控 Debug 起点（如 `slade-join`、`castle-quake`）仅验证对应过场交接，**不等于**自然完整通关，也不携带历史金币或经验。
- **Flag 不唯一决定整个会话**：`Fnnn` 决定场景配置与门槛，但当前在场角色、随行关系、局部地形改写与背包状态还取决于地图进入方式与存档快照。
- **发布边界**：本总览先在主仓完成规范化与验收，**尚未同步至线上 Wiki**。
