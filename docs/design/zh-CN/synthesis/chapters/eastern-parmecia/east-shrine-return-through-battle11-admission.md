# East Shrine 返回至 Battle11 洞窟准入

## 两种出发与洞窟选择

**已确认：**East Shrine 的返回是独立出口，要重新经过地图和遭遇选择；Battle10 胜利则直接把队伍放回大地图。两条都可从当前区域走向洞窟，神殿交谈和新随从不是洞窟准入所需。地图滚动保留当前阵容，并不等同于触发普通洞窟入场。

洞窟入口要有当前解锁才开 Battle11；缺少解锁可先作为探索入场。城堡集会后的推进可提供该解锁，重新进入已经办过集会的城堡并不会自动补缺。选中的 Battle11 开场与当前出战队伍分开，继续挂起战斗不重演开场或重新布阵。原版自然路线和达到第一次可操作时的最终状态仍为**未知**。
