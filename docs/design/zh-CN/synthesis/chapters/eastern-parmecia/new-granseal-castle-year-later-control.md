# New Granseal 城堡：一年后讲话与首次控制交接

## 首访和重复访问

**已确认：**只在一年后集会尚未完成时，城堡初始化先把 EGRESS 的地图设为 New Granseal 城镇，再运行集会。城堡仍是当前地点。国王可在演出中不发言；那是场景安排，不是玩家选择。集会返回后，记录场景完成并解锁后来 Battle11；这次不立刻扫描洞窟遭遇。

再次访问保留传入的 EGRESS 与 Battle11 解锁状态，不重演集会、不重新安排演员，缺失解锁也不会由重复访问补上。集会结束切换到普通在场者；冷重入选中的人群可以受更晚剧情影响。只有无其他待处理事件、当前为步行时才恢复普通探索，实际输入就绪仍为**未知**。
