# Bedoe 返回至 Battle13 准入

## Polca 对峙何时发生

**已确认：**在 Polca 尚未呈现受伤男孩时，该区域先处理他的抵达，本次不对峙。已呈现男孩之后，还要持有接受 Bedoe 国王请求的进度，且对峙尚未完成。对峙优先于同处可能匹配的 Oddler 请求；若对峙没有运行，也不回头尝试其他场景。它不要求此前见过雏鸟或解救乌龟。

场景中 Gerhalt 自请加入，没有玩家拒绝提示。最多十二人的出战容量独立于正式成员资格；满员时他加入后备，不替换已有出战成员，也不因此复活或获得临时随从。场景安排本次战斗请求并解锁，完成后才记录对峙。若后来请求被覆盖而对峙已有记录，再访不会自动补做。全新战斗按当前军团建队，挂起继续用已保存战斗。自然路线与响应输入为**未知**。
