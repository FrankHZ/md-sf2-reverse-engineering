# Volcanon 返回至 Bedoe 国王选择

## 向国王回答

**已确认：**找到并面对现有国王即可普通交谈，事件不要求从特定朝向接近。未接受请求时，提示可选 Yes 或 No，B 与 No 相同。拒绝后国王邀请军团留在 Bedoe，没有场景离开、Luke 调度或接受记录；之后仍可再次交谈。

接受后，国王建议寻找 Creed，请 Luke 安排木筏。场景完成才记下同意。再谈只听到鼓励，不重开选择；重入可能切到新的在场者。Luke 的当前离开并未招募他或授予木筏，实际取得仍要另走 Polca 市长分支。对话结束归还国王原朝向并清理窗口；可用输入还取决于当前事件。自然离开和存档状态仍为**未知**。
