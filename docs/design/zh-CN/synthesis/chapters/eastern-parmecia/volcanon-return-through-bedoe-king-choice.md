# Volcanon 返回至 Bedoe 国王选择

以下为原版已接受的条件与分支。静态规则的实际自然触发以所引证据为限。

返回 Bedoe 后，国王问 Bowie 是否接受 Volcanon 击败 Zeon 的请求。拒绝则邀请队伍留在 Bedoe；接受后建议去找 Creed，并安排 Luke 离场准备木筏。再次交谈给予鼓励。木筏实际取得和登乘仍需后续交互。
