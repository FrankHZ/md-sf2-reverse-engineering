# L2 · 新格兰希尔与东部 Parmecia 章节总览

- **章节范围**：承接 Grans 离岛（[Grans 开篇与离岛章节总览](../grans-opening/chapter-overview.md)），从渡海航行与 Parmecia 迫降起步，经损坏船只的救援战（`Battle08`）、建立**新格兰希尔（New Granseal）**、结识**彼得（Peter）**，向东走过 **Ribble**、**Dark Caves**、**Polca**、**Mount Volcano** 与 **Bedoe / Volcanon**（`Battle09`–`Battle13`），一直到在 Polca 海岸**实际登乘木筏并迈出水上第一步**为止。
- **本章目标与世界变化**：逃难众人渡海迫降、迎战救援失踪工人（`Battle08`）并拆船建起新格兰希尔 → 一年后，会说话的凤凰**彼得**促成东行探索，途经 Ribble（`Battle09`–`10`）与 Dark Caves（`Battle11`）→ 经 Polca 与 Mount Volcano（`Battle12`）登上 Bedoe，**Volcanon** 拒绝直接插手，彼得决心亲自参战并转由玩家直接操控 → 回防 Polca（`Battle13`）招募 **Gerhalt**、向市长换取**木筏**、带上 **Oddler**、正式招募 **Luke**，最终下水开启南部航程。
- **后续内容（不在本 B1 展开）**：南下水路、离筏登岸、沙漠战（`Battle14`）、Kraken 战（`Battle16`）、Hassan、**Wooden Panel / Achilles Sword** 道具链与 **Caravan** 归下一章（`#2366` B2 片；见[剧情推进 · 南方旅行、Caravan 与 Creed](../../themes/story-progression.md#南方旅行caravan-与-creed)）。

## 按情节依赖与时序排列的事件总表（玩家视角）

*下表按**情节依赖**组织，不把可选支线硬排成唯一必经路线。每一条可选或可错过事项都以具体地点与阶段变化为界：*

- **不存在“本章结束前都能回头补做”的统一窗口**：例如 Polca 翻龟救妖精会在拜见 **Volcanon（`E14`）**后关闭，Bedoe 幼鸟救助会在后期南部旅行**招募 Elric（`Battle20`）**后关闭。
- **East Shrine 不是 Dark Caves 的前置**：自然游玩下从 `Battle10` 胜利所在河岸步行直达 East Shrine 并未证实，跳过它完全不阻碍进入 Dark Caves（`E11`）。

## 本章关键物品与木筏流转链

*东部 Parmecia **没有必经主线背包钥匙道具门槛**。**木筏**是由多项独立状态串联起来的载具流程（不占背包格）；后期 Parmecia 的主线道具（**Wooden Panel**、**Achilles Sword**）与 **Caravan** 归属 `#2366` B2 片，而非本章前置（[物品索引（英文源）](../../../../../../remake/docs/content/campaign-items.md)）。*

### 木筏流转链（五个独立环节）

1. **市长授筏（`E17`）：** 战后 Polca 同一次进城内连续对话四次，确立**木筏所有权**（此时人仍在城内步行）。
2. **记下海岸停泊点（`E17`）：** 同一完成步骤另行记录城外大地图南岸的**停泊位置**（所有权与停泊点分开保存；未记录泊位的旧战斗存档可能只有所有权而泊位未知）。
3. **大地图实体出现（`E19`）：** 走出 Polca 南门进入大地图时，才按停泊坐标在海岸生成**停泊中的木筏实体**（独立于 Luke 入队剧情）。
4. **对准登筏（`E20`）：** 朝停放实体木筏的相邻水格迈步，进入**木筏航行模式**（朝其他非对齐水格迈步仍保持步行）。
5. **首次水上移动（`E20`）：** 在水面受控走出第一步即完成本 B1 章节；离筏上岸、跨图水路与 `Battle16`（Kraken）归入 B2 阶段。

## 证据与边界说明

- **原版边界**：本章全部段落（`E1`–`E20`）在锁定源码（`SF2DISASM` `c834c652b6862bc5679fd7f69a38a7093206efc6`）与美版 ROM 中为**已确认静态**（[原版剧情覆盖（英文源）](../../../../../research/story-content-coverage.md#eastern-parmecia-ribble-polca-and-bedoe)）。原版运行时观察仍止于前期 `Map3`–`Battle01`；本章自然连续步行、渡筏前能否步行抵达 East Shrine、硬件时序与原版断电存档持久性仍为**未知**。
