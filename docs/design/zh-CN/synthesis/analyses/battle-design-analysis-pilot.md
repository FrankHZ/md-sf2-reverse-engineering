# 战斗设计分析 · 三种战术压力

以下是**推断**的设计解读，用特定入场与规则讨论可行的准备和行动。源于原版静态内容及明确的对局假设。自然移动、目标及伤害历史仍有**未知**。参阅[英文分析与操作数依据](../../../synthesis/analyses/battle-design-analysis-pilot.md)。

## Battle01：让小队彼此照应

敌人分布使靠近与进攻的先后有意义。可以让前排先停在增援可到的格子，使攻击与治疗互相覆盖；也可以让小队一同进逼，减少领先者在敌方行动前孤立的机会。要比较的是谁在下一次敌人行动前还有合法目标或支援位置。参阅[开篇至 Battle01](../chapters/grans-opening/opening-through-battle01.md)及[战场寻路](../../contracts/battle/battlefield-navigation.md)。

## Taros：保护能对首领造成伤害的角色

普通物理伤害闸门要求 Bowie 实际装备 Achilles Sword。仅持有剑不足以承担这项战术角色。可以先处理护卫，为 Bowie 留住进入交战的位置和支援；也可以在符合出手与支援条件时集中突破，代价是让更多敌人仍可行动。参阅[Taros 与 Caravan](../themes/story-progression.md#完整示例taros-与-caravan)及[物理交战](../../contracts/battle/combat-resolution.md)。

## 棋盘：决定何时扩大交战

Battle22 的不同敌人各有可接近范围和激活条件。较紧的阵线可以先处理接近的一翼，以保留支援；散布轻伤可让多个待机棋子提前行动；击倒部分棋子还会使更多棋子进入活跃状态。若实际能到达并得到支援，也可优先攻击 King。Bowie 存活且首领清理完成时，不用逐个消灭全部棋子，代价是要承担周边远程、法术和治疗角色的威胁。参阅[棋盘初始队伍](../chapters/southern-travel-creed/battle22-initialization-and-roster.md)和[棋盘结果](../chapters/southern-travel-creed/battle22-outcomes-and-desktop-return.md)。
