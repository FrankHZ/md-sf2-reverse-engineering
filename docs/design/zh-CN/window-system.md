## 已确认的静态合同

原版有八个固定 16 字节条目。每个条目持有一个布局地址/激活测试长字、两个打包尺寸字节、六个打包位置/原点/目标字节、两个动画控制字节，以及两个源码未标注字节。一次布局分配消耗 `width * height * 2` 字节；这是一个布局字公式，而非渲染器缓冲或容量保证。分配游标在成功创建时推进，并在删除后从最高的剩余布局地址重新计算。

坐标以 X 在高字节、Y 在低字节的方式打包。条目查找使用 16 的槽位步长；格子查找使用 `layout + (Y * width + X) * 2`。组合使用 32 格、64 字节的地图布局行步长，源码检查保护其 `<32` X 与 `<28` Y 边界。重制版应把坐标打包与布局字寻址保留为导入/保真边界，同时在不需要一致性的地方选择自己的内部数据表示。

移动保留打包的原点、目标、长度与计数器状态。普通移动在写入原点/目标/长度之后重置计数器；Special Turbo 强制长度为 1。每次 VInt 在插值与重新组合之前恢复移动中的窗口，在位域中追踪移动中的槽位，应用隐藏/固定路径，并在启用 DMA 队列处理之前有条件地提交合并后的 Plane-A 布局。确切的可见结果、完成帧与队列行为有意地不在此合同范围内。

## 重制边界

重制版可以把分配、移动、组合与延迟呈现暴露为独立服务。在想要原版保真的地方应保留已确认的顺序，把源码未标注字节作为不透明的兼容状态保留到运行时工作解释它们为止，并把裁剪、滚动摄像机、缓冲容量、DMA 模拟、音频反馈与呈现时序作为显式的实现选择。
