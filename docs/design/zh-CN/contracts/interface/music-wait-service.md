# L3 · 有限音乐等待

重制已接受的有限音乐规则把音乐实际播放与玩法逻辑的完成分开处理。需要等待有限音乐的场景同时要求逻辑时间达到终点，以及匹配曲目实际播完。前者达成后，音频迟到不再增加玩法时间或随机判定；后者先达成也不能跳过逻辑工作。恢复上一首曲目后，场景才能继续。循环曲目、玩家确认和真正要求效果结束的等待各自保留独立的准入条件。

这项决定可能影响后续随机序列。采用它的场景应保留必需的剧情、资源和控制后果。参阅[现代有限音乐决定（英文源）](../../../contracts/interface/music-wait-service.md#accepted-modern-finite-music-policy)及[重制愿景](../../game-vision.md)。
