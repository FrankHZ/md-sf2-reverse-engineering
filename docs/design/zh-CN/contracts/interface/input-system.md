# L3 · 输入与控制上下文

**已确认：**自由移动、菜单选择、等待继续和不可操作的场景分别消费相应输入。方向会改变朝向或选择；确认、取消与打开场地菜单的作用取决于当前控制上下文。已有事件与 A/C 同次进入探索处理时，先处理事件。重制保留明确的输入归属，并在必要场景和交互完成后恢复操作。参阅[地图探索](../world/map-exploration.md)、[对话与选择](dialogue-system.md)、[键盘布局的产品决定](../../game-vision.md#保真与现代化)和[原版输入依据（英文源）](../../../contracts/interface/input-system.md)。

**已确认：**原版派生的长按重复在保持输入后先等 24 帧的计数门槛，之后按六帧节奏重复。接受当前输入与等待新按下的服务各自工作；释放再按可产生新的输入。以上适用于原版输入阶段，端到端输入延迟仍为**未知**。
