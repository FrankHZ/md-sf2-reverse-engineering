# L3 · 对话、确认与选择

**已确认：**连续发言、单独窗口、关闭及清空具有各自的控制边界。文本展开完成后，普通对话仍需到达自己的确认环节才能继续。Yes/No 提示把选择交给实际场景。拒绝可能结束、退回选择或进入重问，按场景分支决定。窗口、立绘和说话者的选择随当前对话条件而变；一个文本引用本身不足以证明可见完成或回复后可操作。

在支持快进的重制场地剧情中，当前文本段落可见时，新按一次确认可结束该段的短暂停顿（D1），包括接连出现的短暂停顿。文字和窗口随后按原顺序处理。若同一段读完并进入确认等待，这次按键也可由该段的确认环节正常接收。换段、清屏或失去当前输入控制权后，需要新的按键。长停顿（D3）保留单独的持键打断规则，打断后仍需确认。参阅[场地剧情等待中的确认规则（英文源）](../../../../../remake/docs/application/session-and-programs.md#confirm-during-field-story-waits)。

重制已接受的快显语音规则见[重制愿景](../../game-vision.md#保真与现代化)。参阅[地图交谈与返回](../../synthesis/themes/map-design-principles.md#对话与继续执行)及[原版对话及适用边界（英文源）](../../../contracts/interface/dialogue-system.md)。

## 继续与拒绝

**已确认（静态）：**原版普通对话内的一种继续等待接受方向或 A/B/C，包括当前持有输入；这次成功轮询同样会推进随机状态。选择提示则由自己的消费者读取答案，B 可作为拒绝，后续是退出、保留重试，还是立即重问，要看场景。需要新按键的等待与仅需当前持有的等待不能互换。等待的实测硬件节奏仍为**未知**。
