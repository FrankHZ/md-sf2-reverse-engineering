# L3 · 对话、确认与选择

**已确认：**连续发言、单独窗口、关闭及清空具有各自的控制边界。文本展开完成只让玩家读到整段；仍需独立确认才能继续，具有 Yes/No 的提示则把选择交给实际场景。拒绝可能结束、退回选择或进入重问，按场景分支决定。窗口、立绘和说话者的选择随当前对话条件而变；一个文本引用本身不足以证明可见完成或回复后可操作。

重制已接受的快显语音规则见[重制愿景](../../game-vision.md#保真与现代化)。参阅[地图交谈与返回](../../synthesis/themes/map-design-principles.md#对话与继续执行)及[原版对话及适用边界（英文源）](../../../contracts/interface/dialogue-system.md)。
