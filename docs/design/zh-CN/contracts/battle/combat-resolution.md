# L3 · 物理交战

以下规则在所列的原版路径已**确认**。参阅[物理交战合同（英文源）](../../../contracts/battle/combat-resolution.md#confirmed-resolution-pipeline)与[Battle02 首次接敌](../../synthesis/analyses/battle02-first-contact.md)。

## 闪避与伤害

1. 先判闪避，成功则跳过伤害。原版已观察地面非弓手攻击悬浮目标时，从 0–7 掷出 0 闪避；其他武器和移动组合按各自条件。
2. 基础伤害为 `max(当前 ATT − 当前 DEF, 1)`。按目标地形，把伤害分别乘以 256、230 或 205 后除以 256，向下取整。特定弓手类攻击飞行或悬浮目标，在地形削减后加四分之一，向下取整。
3. 已确认的首击会心分支在 0–31 掷出 0 时成立，加上当下伤害的一半，向下取整。反击的半伤在浮动前计算。
4. 用浮动前伤害确定共同范围 `floor(伤害 / 8) + 1`。从 0 到范围减 1 各掷一次，连续减去两次结果。最终 HP 不低于零。

## 追加攻击与回放

首击后才考虑二连击，再处理反击。目标死亡会拒绝后续攻击；同侧目标或攻击者处于 MUDDLE 排除二连击。同侧、超出反击范围、睡眠或眩晕排除反击。Burst Rock、Kraken Head、Prism Flower、Zeon Guard 作为受击者不能反击；Taros 主动攻打时对方不能反击。二连击读取首击后的临时 HP，反击交换行动者与目标。正式回放按同一顺序应用 HP 变化。

MUDDLE 持续期间行动可交给 AI。只有带二级混乱且仍有计数时，目标判定才翻转阵营关系。已确认的最终守卫保护 Bowie 或首个敌方槽，自我瞄准需在 0–1 掷出 0，选中同侧其他对象无需该掷骰。

## 经验、金币与掉落

每个行动的伤害和击杀 EXP 累积上限 49。行动者有效等级减目标等级，小于 3 得击杀档 50，差 3/4/5/6 分别为 40/30/20/10，再高为 0。转职行动者在此比较加 20。Battle01 对敌奖励向下减半，再作两次 0–15 判定，第一次为零加 1、第二次为零减 1，最低发 1。存储 EXP 上限 200，后续阈值见[升级](../party/level-up.md)。

击杀金币依敌人而定，军团金币上限 9,999,999。匹配战斗、敌人和持有物后，指定稀有武器先掷 0–31，零才通过；再检查一次性状态，成功才移除并交付物品。无法交给行动者时，稀有物品可进入特卖，其他物品丢弃。特卖每件最多 15。参阅[成长与经济](../../synthesis/themes/progression-and-economy.md)。
