# L3 · 升级与属性刷新

**已确认：**正式接收战斗 EXP 时，先累加，达到 100 则扣除一个阈值并尝试升级。一次奖励最多尝试一次升级。普通职业的等级上限为 40，转职后为 99。当前职业、存储等级和奖励比较用的有效等级分别处理。

升级应用增长，增加等级，检查对应等级的法术学习，然后刷新派生属性。提高 HP/MP 上限不回复当前 HP/MP。刷新采用新的基础属性，再应用保留的状态与已装备物品贡献及相应上限。转职的刷新与升级有不同输入，参阅[装备与转职](../../design-map.md#装备与转职)。

参阅[增长与学习](../../synthesis/themes/progression-and-economy.md#队伍发展)、[升级原版依据（英文源）](../../../contracts/party/level-up.md)和[成长数据（英文源）](../../../../research/party/ally-growth.md)。

## 增长计算与特例

**已确认：**按 HP、MP、基础 ATT、DEF、AGI 顺序处理。无成长曲线的属性增加零且不掷骰。每个有曲线的属性从两个 0–127 抽样；以成长投影 P、本级比例 f、累计比例 F（均以 256 为分母）计算：

```text
本次增益 = floor((P × f + 抽样1 − 抽样2 + 128) / 256)
预期下限 = 初始值 + floor((P × F + 128) / 256)
若当前值加本次增益仍低于预期下限，本次增益再加 1
```

成功升级后只检查与有效等级恰好匹配的学习阈值。转职后法术学习有效等级包含 20 的偏移；TORT 在原版也误走偏移分支，Kiwi 没有对应法术可学。Karna 的初始 HEAL 3 在自然用例中另使二连由 1/32 变为 1/16；普通升级仍习得该法术。一般原版属性刷新先应用状态，再加装备；观察到普通 ATT/DEF 上限 200、基础敏捷上限 100（双行动资格另计）。敌方仍获得物品属性，但不会因装备再得到诅咒。
