# L3 · 已学法术与可用等级

**已确认：**符合职业和等级的学习条目可以增加一种法术或提高其已学最高等级。提高等级时仍可从已学范围选用较低等级。实际施法还要满足当前 MP、目标、位置和沉默资格。某些职业转换另行处理现有法术书，参阅[转职](../../design-map.md#装备与转职)。

参阅[升级与学习](level-up.md)、[法术结算](../battle/spell-resolution.md)及[法术书原版依据（英文源）](../../../contracts/party/spellbook-state.md)。

## 空位与学习顺序

**已确认（静态）：**先在现有法术中找相同基础法术。已经会同级或更高级就保留；学到更高级直接替换该条。完全未学过才找空位；没有空位时不能加新法术，也没有询问忘记旧法术的分支。已学数量不因选了一个较低施放等级而改变。
