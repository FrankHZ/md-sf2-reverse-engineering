# L3 · 队伍、出战与随从

**已确认：**正式加入后才拥有军团成员资格。当前出战名单受容量限制；已加入的后备成员仍可有独立的服务和携带栏资格。临时跟随属于当前探索场景，不能据此判定已经加入或可以出战。战斗中的 AI 控制同样单独选择。回到地图时可能按出战名单和剧情条件重新建立在场成员和随从。

参阅[成长与经济](../../synthesis/themes/progression-and-economy.md#加入参战跟随与存活)、[剧情推进](../../synthesis/themes/story-progression.md)与[队伍及名册依据（英文源）](../../../contracts/party/party-roster-state.md)。

## 加入后是否立即参战

新加入在出战人数少于十二时通常自动分配出战位，满队可仍收为后备。加入不治疗、重置属性或耗费物品。剧本可以另行强制入队或换人，如 Battle32 的 Jaro 叛离满队也参战，之后的首次胜利加入却会撤下其出战位；Battle33 开场另为 Frayja 选择替补。参阅[两个遭遇的成员规则](../../synthesis/themes/story-progression.md#jaro-叛离frayja-加入与-moun-幸存者)。
