# L3 · 存档、返回与继续

## 探索与教堂

关闭教堂服务可以回到当地探索；只有接受保存才尝试写入记录。保存用的返回地点与实际重建的场景分别选择。取消保留已有返回地点。重制从稳定的场地状态检查可保存资格，确认后记下新的返回地点和允许恢复的当前场景。败北与 EGRESS 仍走各自的费用、恢复和目的地规则。参阅[服务交互](../party/service-interactions.md)及[重制场地保存资格（英文源）](../../../../../remake/docs/application/opening-session-lifecycle.md#eligibility-and-restoration-recipes)。

## 女巫菜单与挂起

**已确认：**New Game、Continue、Delete 和 Copy 有各自的存档有效性、源槽和目标槽条件。选择可继续的挂起战斗沿已有队列与战斗状态恢复；新进入遭遇则重新准备。参阅[女巫菜单条件（英文源）](../../../contracts/system/save-system.md#confirmed-witch-save-menu-action-admission-matrix)与[战斗生命周期](../battle/battle-control-lifecycle.md)。

重制仅在已准入的、稳定而可恢复的场地及战斗控制点保存。读取不兼容或损坏的记录时保留当前会话和原记录，按明确的恢复选择处理。各服务调用与原版长期持久性的观察边界，参阅[存档合同（英文源）](../../../contracts/system/save-system.md)和[战斗保存及继续（英文源）](../../../../../remake/docs/application/battle-save-and-continue.md)。

## 两个存档槽的女巫菜单

**已确认（静态及受限验证）：**没有有效存档时可新建；仅一个有效存档时可新建、继续、删除或复制；两个有效槽都占用时只有继续和删除。新建选择空位并从开局保存，继续及删除选择有效占用槽。复制以唯一有效的槽为来源，确认后复制到另一槽。删除确认后将该槽标为空闲。取消槽位选择或拒绝确认回菜单而不执行操作。

读取探索存档按该地图存档点继续，读取已获准的挂起记录才沿保存的战斗继续。教堂在成功保存之后另有继续或挂起分支；首次拒绝则不保存。原版断电后的耐久性与未观察到的完整场景返回仍为**未知**。
